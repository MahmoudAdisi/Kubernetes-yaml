Kubernetes Deployment & Configuration Project
•	Built and deployed multiple Kubernetes resources including Pods, Deployments, ReplicaSets, DaemonSets, and Services to simulate production-grade workloads.
•	Configured advanced scheduling techniques using Tolerations and Node Affinity to control workload placement.
•	Implemented different update strategies (Recreate, RollingUpdate) to understand application availability and release management.
•	Designed networking components such as ClusterIP Service and Ingress for routing external traffic.
•	Managed persistent storage using PersistentVolumes and PersistentVolumeClaims.
•	Automated tasks using Jobs and CronJobs for scheduled workloads.
